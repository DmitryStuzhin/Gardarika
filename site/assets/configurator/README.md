# Калькулятор дома (MVP)

`site/calculator.html` — пошаговый калькулятор, в котором дом собирается из частей разных проектов.
Готовы три модели: Lento 100, Lilia 105, Garden 106 (в `data.js` у них `calc: true`). Остальные проекты на сайте помечены «Расчёт в разработке».
Шаги: проект → пятно и фундамент (основной объём, пристройки) → стены → второй уровень → кровля → окна и фасад → инженерия и отделка → смета и PDF. После выбора проекта дом строится с нуля: модель показывает этап шага, новый слой опускается на место; части других домов выбираются на своём этапе.
`constructor.html` перенаправляет сюда. Старый 11-шаговый калькулятор собран в `calculator-legacy.html` как архив, с сайта на него ссылок нет.

## Как устроено

| Файл | Что делает |
|---|---|
| `houses.js` | Библиотека частей: у каждого дома основной объём, верхний уровень, кровля и пристройки. Здесь же общие кровли и варианты отделки со ставками. |
| `engine.js` | Раскладка пристроек по стенам (без пересечений), правила совместимости, поиск одного исправления для конфликта, массинг — единый список объёмов. |
| `pricing.js` | Смета по объёмам массинга: площади стен, скатов, проёмов, фундамента. |
| `geometry.js` | 3D-модель из того же массинга, по этапам стройки. |
| `calc.js`, `calc.css` | Пошаговый интерфейс калькулятора. |
| `pdf.js` | Смета в PDF; jsPDF и шрифт (`assets/vendor/`) грузятся по нажатию кнопки. |
| `../../tools/test-constructor.js` | Автотест всех сочетаний: `node site/tools/test-constructor.js`. |

Модель и смета считаются из одного массинга, поэтому не могут разойтись.
Конструктив и отделка (фундамент, стены, кровля, фасад, окна, инженерия, внутренняя отделка) подходит к любой части и не влияет на совместимость формы, кроме явно записанных инженерных правил.

## Как добавить дом

1. Добавить вызов `GC.registerHouse({...})` в `houses.js` (или отдельным файлом, подключённым после него):
   - `core` — размеры основного объёма `w`, `d`, высота стен `wallH`, цоколь `plinth`, окна по сторонам;
   - `upper` — `{type:"floor", wallH}` или `{type:"mansard", knee}` либо `null`;
   - `roof` — `{family:"gable"|"hip"|"flat", pitch}`;
   - `annexes` — пристройки: `kind`, `along` (длина вдоль стены), `depth`, `h`, `roof`, допустимые стороны `sides`, выравнивание `align`.
   - у каждого размера поле `src`: `published`, `plan` или `inferred` — допущения показываются клиенту.
2. Добавить `calc: true` этому дому в `assets/js/data.js`, чтобы на сайте появилась кнопка расчёта.
3. Запустить автотест. Он проверит пересечения, работающие исправления и «мёртвые» варианты во всех сочетаниях с уже существующими домами.
4. Если нужен новый запрет — дописать правило в `GC.rules` (engine.js): условие `when`, проверка `test` и понятное сообщение `message`. Правила с `kind: "pilot"` — инженерные допущения, их проверяет инженер.

## Что пока упрощено

- Окна — панели на фасаде без вырезов в стенах; внутренних планировок нет.
- Крыло наследует систему кровли дома; сложные ендовы не моделируются, стыки только Т-образные.
- Ставки демонстрационные, инженерные правила (`kind: "pilot"`) требуют проверки.
- Инженерия и внутренняя отделка на модели не показываются — это сказано рядом с выбором.
