# Гардарика — тестовый редизайн «Монолит»

Тёмная архитектурная концепция на основе бесплатного промпта **Monolith Hero** (MotionSites, категория Architecture), адаптированная под Гардарику.

Из промпта взяты:
- главы на весь экран со сменой сцены и маской заголовка;
- волосяная рамка с фасками и док снизу;
- метки, которые «раскручиваются» по буквам;
- параллакс за курсором.

Видео со сторонним каменным кубом заменены на собственные визуализации проектов. Латинские шрифты заменены кириллическими: Tektur (OFL) и Golos Text.

Все тексты, площади, контакты и описания проектов взяты из `reference/index.src.html`, без выдуманных фактов.

## Вау-слой (v2)
1. **Первый экран.** Фото Pine 141. Под курсором мягкий круг-прожектор открывает чертёж того же кадра (`house-141-blueprint.jpg`, получен из фото выделением контуров). Механика прожектора — по промпту Lithos (MotionSites). Если курсор стоит, прожектор сам гуляет по фасаду, поэтому эффект виден и на телефоне.
2. **«Провал».** При прокрутке кадр увеличивается в 10 раз к освещённой двери, текст улетает на зрителя, тёплый свет из двери переходит в синюю чертёжную сцену.
3. **Стройка в 3D** (Three.js из `reference/`). Прокрутка ведёт по 7 этапам: разметка, плита, кладка блоками ряд за рядом, стропила и кровля, штукатурка и окна. Дальше дверь открывается, камера проходит через гостиную, сквозь раздвижное окно выходит на террасу и разворачивается к дому в сумерках. Это иллюстративная модель, не конкретный проект.

## Запуск
Откройте `redesign/index.html` в браузере. Работает и с `file://`, внешних запросов нет.
Кнопки 3D-конструктора ведут на действующие `reference/calculator-v2.html` и `reference/calculator-lento-100.html`.

## Один файл для просмотра
`gardarika-redesign.html` — та же страница, в которую встроены все фото и шрифты (≈6,5 МБ, включая Three.js). Её можно открыть в любом просмотрщике, включая предпросмотр в приложении Claude, и переслать как один файл. Пересобрать после правок: `python3 redesign/build.py`.
Ссылки на 3D-конструктор в этой версии работают, только если файл лежит в папке `redesign/` репозитория.

## Состав
- `index.html` — вся страница: первый экран с 6 главами, принципы, каталог из 13 проектов с фильтром и окном проекта, метод, материалы, конструктор, контакты.
- `assets/img` — сжатые визуализации и планы из `reference/catalog`.
- `assets/fonts` — Tektur, Golos Text и Playfair Display Italic (OFL).
- `assets/js/three.min.js` — Three.js r140 (MIT), копия из `reference/`.
