# Гардарика — тестовый редизайн «Монолит»

Тёмная архитектурная концепция на основе бесплатного промпта **Monolith Hero** (MotionSites, категория Architecture), адаптированная под Гардарику.

Из промпта взяты:
- главы на весь экран со сменой сцены и маской заголовка;
- волосяная рамка с фасками и док снизу;
- метки, которые «раскручиваются» по буквам;
- параллакс за курсором.

Видео со сторонним каменным кубом заменены на собственные визуализации проектов. Латинские шрифты заменены кириллическими: Tektur (OFL) и Golos Text.

Все тексты, площади, контакты и описания проектов взяты из `reference/index.src.html`, без выдуманных фактов.

## Запуск
Откройте `redesign/index.html` в браузере. Работает и с `file://`, внешних запросов нет.
Кнопки 3D-конструктора ведут на действующие `reference/calculator-v2.html` и `reference/calculator-lento-100.html`.

## Состав
- `index.html` — вся страница: первый экран с 6 главами, принципы, каталог из 13 проектов с фильтром и окном проекта, метод, материалы, конструктор, контакты.
- `assets/img` — сжатые визуализации и планы из `reference/catalog`.
- `assets/fonts` — Tektur и Golos Text.

Форма заявки не имитирует отправку: она открывает письмо на info@gardarika.moscow. Для настоящей отправки нужен бэкенд или сервис форм.
