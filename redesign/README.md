# Гардарика — редизайн «Лес и стройка»

Главная страница в виде одного непрерывного прохода по прокрутке:

1. **Лес.** Первый экран — густой лес (`media/forest.jpg`). Заголовок стоит между стволами: крайние сосна и берёза (`media/trunks.webp`, вырезаны по зелёному фону из `img-00-les-front`) лежат поверх текста. За курсором слои сдвигаются с разной скоростью, в лучах летит пыль.
2. **Заголовок уходит в подлесок.** При прокрутке текст медленно опускается за кусты: нижняя часть того же кадра лежит поверх текста.
3. **Поворот на поляну.** Лес уезжает влево, ближние стволы — быстрее фона. Поляна (`media/clearing.jpg` — первый кадр стройки) выезжает справа с растушёвкой и лёгким смазом движения.
4. **Стройка.** Шесть видео (`media/build-1…6.mp4`) проигрываются прокруткой вперёд и назад. Сверху подписи этапов, номер этапа и готовность. Ролики склеены с переходом 0,25 с. Первый грузится сразу, остальные по очереди.
5. **Готовый дом.** Финальный кадр с прожектором-чертежом под курсором (`media/final-blueprint.jpg`) и кнопками.

Ниже — принципы, каталог из 13 проектов, метод, материалы, конструктор и контакты.

## Откуда медиа
Исходники лежат в `gardarika new calculate/`: видео Veo 3.1 и картинка стволов. Подготовка:
- ролики склеены, частота 12 кадров/с, 1600×900, H.264 с ключевым кадром каждые 8 кадров (так быстрее перемотка), по одному файлу на этап, ~3,7 МБ каждый;
- `forest.jpg` — первый кадр `forest-video.mp4`; стволы совмещены с ним скриптом (масштаб 0,703);
- `final.jpg` — последний кадр стройки, `final-blueprint.jpg` — его контурный чертёж.

Тексты, площади, контакты и описания проектов взяты из `reference/index.src.html`. Подписи этапов общие, без обещаний сроков и цен. Визуализация помечена как иллюстративная.

## Запуск
Откройте `redesign/index.html` через локальный сервер, который отдаёт файлы по частям (Range), например `npx http-server redesign -p 8080`. Без этого перемотка видео прокруткой может не работать; встроенный `python3 -m http.server` такого режима не поддерживает.
